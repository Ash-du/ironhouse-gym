# Ironhouse Gym

A single-page gym website: interactive barbell loader, day-by-day class schedule, plate-themed pricing and a booking form.

Plain HTML, CSS and JavaScript. No build step.

## Run
Open `index.html` in a browser, or serve it: `python3 -m http.server`.

## Deploy
Enable GitHub Pages (Settings → Pages → deploy from `main`, root folder).

## Notes
The booking form is a front-end demo. Connect it to your own backend or a form service to receive requests.
